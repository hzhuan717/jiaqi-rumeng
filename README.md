# 佳期如梦 · 噜妹与黄哥的时光之书

黄瀚哲写给噜妹（罗佳）的互动故事书网页，全部内容基于**真实微信聊天记录**（94,383 条消息）整理而来。

纯原生 HTML/CSS/JavaScript 实现，零依赖，部署于 GitHub Pages。

## 运行方式

```bash
npm run dev      # 本地开发（http://localhost:5173）
npm run build    # 打包到 dist/
npm run preview  # 预览构建产物
```

## 真实故事线（共 11 页）

封面 → 序章 → 初识（2025.10.20 加好友）→ 初见（2025.10.21 罚款200）→ 喜欢（表白）→ 在一起（2026.01.07，密码门）→ 噜妹小百科 → 时光相册 → 记忆小屋（小游戏）→ 520与每日心签 → 终章情书

- **真实昵称**：解锁词为「噜妹 / 罗佳 / 宝宝 / 蠢猪」等聊天中的称呼
- **真实日期**：初见 2025.10.21、在一起 2026.01.07，天数实时自动计算
- **真实梗**：噜噜噜、蠢猪、略略略、超级无敌雷霆旋转三百六十度想、罚款200、小兔子帽子、柿子树下的小猫
- **真实故事**：每章内容均取自聊天记录原文
- 详细时间线见 [`时间线.md`](时间线.md)

## 玩法

- 时光碎片 ×5（集齐解锁终章）：序章之约 / 初见之页 / 在一起之门（密码0107）/ 记忆小屋（游戏通关）/ 相册星光（点3颗星）
- 记忆小屋：翻牌配对、接爱心、戳泡泡
- 每日心签：按日期自动换签 + 手动重抽
- 祝福生成器：访客输入名字得专属祝福
- 每日书摘、节日感应、背景音乐、震动反馈
